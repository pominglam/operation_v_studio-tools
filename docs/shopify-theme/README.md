# Shopify Online Store theme (static pages)

This Laravel repo does **not** embed the storefront theme source.

**Canonical theme workspace (CLI + Cursor):** sibling folder **`../ovs-shopify-theme`** (outside `pricing-tool`) — Shopify **Rise** theme pulled from the live shop, Git branch **`about-us-draft`**.

Theme assets **also** exist in Shopify Admin after deploy; duplicate/unpublished workflows remain valid for previews.

Static page work (About Us placeholder, workflows, previews) is specified here:

- **[Static pages workflow + About Us handoff](./static-content-pages-workflow-and-about-us.md)** — rules, duplication/preview gates, SEO/a11y, content, suggested JSON blocks, CTAs.

For Admin API OAuth and ERP mirrors, see **[Shopify ERP integration](../shopify-integration/README.md)**.
