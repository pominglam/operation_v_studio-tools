# Marketing notes

Sheet **Other** column: restock posts, influencer videos, ads. These are **not** that day’s sales. Marketing usually shows up later, so we do not attach order $ or Event $ to the note date.

## Now

Each note is: **when** it happened, **what** (short name), optional **notes**.

Later a sales chart can mark these dates without assigning that day’s POS to the campaign.

In-store events stay on [store-events](store-events.md).
